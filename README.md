# Skill Nexus Assignment 2

This repository contains the backend projects developed for Skill Nexus Assignment 2.

## Projects

### 1. To-Do REST API
A REST API for managing tasks.

Features:
- Create tasks
- Get all tasks
- Update tasks
- Delete tasks
- MongoDB database integration

### 2. User Authentication API
An authentication system using Node.js, Express and MongoDB.

Features:
- User registration
- Password hashing using bcrypt
- User login
- JWT token generation

### 3. Notes App Backend
A secure backend for managing personal notes.

Features:
- Create notes
- Get notes
- Update notes
- Delete notes
- JWT-protected routes
- MongoDB database integration

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Postman

## Security

Environment variables such as MongoDB credentials and JWT secrets are stored in `.env` files and are excluded from GitHub using `.gitignore`.
